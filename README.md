# Playwright AI Automation

## Overview

This project demonstrates AI-assisted Playwright test automation using JavaScript.

The project explores how AI tools can support QA automation by helping with test development, test execution, troubleshooting, and automation workflows.

## Automation

The project uses Playwright to automate application testing and includes GitHub Actions workflows to support automated test execution.

AI-assisted development is used to help create, analyze, and improve automation workflows while keeping the final test implementation under QA review.

## How to Run

Install dependencies:

```bash
npm install
```

Run Playwright tests:

```bash
npx playwright test
```

Run tests with the browser visible:

```bash
npx playwright test --headed
```

View the HTML test report:

```bash
npx playwright show-report
```
